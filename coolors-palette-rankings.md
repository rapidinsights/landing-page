# Coolors Trending Palettes — Ranked for Rapid Insights Consulting

Scored against: B2B data consulting brand targeting non-technical SMB owners (10–100 employees). "Knowledgeable friend" tone. Current brand direction: "Refined Gold" (charcoal + amber/gold + white). Ideal formula: blue-family primary for trust + warm accent for approachability + clean neutral system. 60-30-10 rule. WCAG AA contrast required.

**Scoring criteria (10 points max):**
- **Trust Signal (0–3):** Does it contain navy/teal/indigo tones that convey consulting authority?
- **Warmth/Approachability (0–2):** Does it have amber/coral/gold accents that say "knowledgeable friend"?
- **CTA/Conversion Power (0–2):** Does it provide high-contrast accent colors for CTAs on white backgrounds?
- **Brand Alignment (0–2):** Does it fit the "Refined Gold" direction or the recommended palette formulas?
- **Differentiation (0–1):** Does it avoid generic medium blue? Does it feel distinct in consulting?

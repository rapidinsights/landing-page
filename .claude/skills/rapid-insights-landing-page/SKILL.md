# Rapid Insights Landing Page Skill

## Company Context

**Rapid Insights Consulting** — data & analytics consulting for growing businesses.

- **Target audience:** Non-technical SMB owners (10–100 employees) drowning in spreadsheets
- **Core positioning:** "Escape spreadsheet hell" — replace manual spreadsheets with automated dashboards
- **Goal of the page:** Book a free "Data Health Check" discovery call
- **Tone:** Knowledgeable friend — confident, direct, warm, jargon-free
- **Reading level:** 5th–7th grade. Business outcomes, never technical language.

## Three Non-Obvious Principles

1. **The discovery call framing matters more than page design.** Position it as a "Data Health Check" where the prospect *receives* a deliverable (top 3 bottlenecks identified), not *gives* their time.
2. **Specificity is the secret weapon.** "We replaced 17 spreadsheets with 1 dashboard in 6 weeks" does more work than any amount of polished design.
3. **Straightforward headlines outperform creative ones 88% of the time** (15.4% vs 7.1% conversion). Say exactly what you do in plain language.

## Three Modes

### Mode 1: Write Copy

When writing or rewriting copy for a specific section:

1. Read [references/section-blueprints.md](references/section-blueprints.md) for that section's blueprint (elements, formats, examples)
2. Read [references/copywriting-guide.md](references/copywriting-guide.md) for frameworks and jargon translation
3. Apply these rules to every line:
   - Run the "So What?" ladder — keep asking "so what?" until you reach a business outcome
   - Check the jargon translation table — never use technical terms
   - Apply the We/You test — "You" should dominate over "We"
   - Use specific numbers ("$47K", "15 hours/week", "6 weeks") not vague claims
4. Present 2–3 options for headlines/CTAs with reasoning for each

### Mode 2: Plan Structure

When planning or restructuring the page layout:

1. Read [references/section-blueprints.md](references/section-blueprints.md) for the full 10-section structure
2. Follow this arc: problem recognition → solution understanding → trust building → action
3. The 10 sections in order:
   - Hero (above the fold)
   - Logo bar / social proof strip
   - Problem agitation ("Sound familiar?")
   - Solution & value stack
   - How it works (3 steps)
   - Case study / results + testimonials
   - About the founder / guide
   - FAQ / objection handling
   - Risk reversal
   - Final CTA
4. Place CTA buttons after hero, after problem section, after testimonials, after case study, and at page bottom
5. For long-form B2B services: 1,500–3,000+ words outperform short pages

### Mode 3: Review / Audit

When reviewing an existing page:

1. Read [references/review-checklist.md](references/review-checklist.md) for the full audit framework
2. Run the 12 Conversion Killers check first (quick wins)
3. Do the section-by-section audit
4. Score against CRO benchmarks (target: 4–5% conversion, 7%+ excellent)
5. Flag the top 3 highest-impact fixes with specific recommendations
